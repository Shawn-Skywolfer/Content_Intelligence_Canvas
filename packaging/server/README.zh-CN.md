# 内容智能工作台：Windows 独立服务部署

本包只走 Windows 工作站链路。服务名使用 `WinOs` 前缀，例如 `WinOsContentIntelligenceWorkbench`。不需要、也不依赖 Linux/K8s、S3 或单独的静态前端服务。

## 平台配置

1. 上传本 ZIP 并解压，保持 `runtime` 与 `WinOs_ContentIntelligenceWorkbench.exe` 同级。平台启动命令设置为 `WinOs_ContentIntelligenceWorkbench.exe`，工作目录为解压根目录。
2. 配置环境变量：`CIC_SERVER_PASSWORD` 为至少 12 字符的管理员密码；`CIC_SERVER_USERNAME` 默认为 `admin`。
3. 平台注入的 `PORT` 优先作为监听端口；未注入时使用 `CIC_SERVER_PORT`，默认 8000。`CIC_SERVER_HOST` 默认 `0.0.0.0`。
4. **必须配置持久目录**：设置 `CIC_DATA_DIR`，例如 `D:\AppData\ContentWorkbench`。允许服务账号读写；升级或重新部署不得清除此目录。
5. 将该端口映射到平台提供的 HTTPS 网页地址，前端和 `/api` 都转发到同一进程。浏览器首次访问会弹出账号密码登录框。
6. 使用平台网页链接访问应用。健康探针为 `/api/health`，同样需要 Basic 登录凭据；若平台探针无法附加凭据，应使用 TCP 探针。不要添加第二个 Python worker 或进程副本。

无需安装 Python/Node.js；运行时与构建完成的中文网页都在包内。不要使用桌面版的浏览器弹出或缓存解压流程启动本服务。平台停止服务时需要同时停止子进程；按 Windows 应用进程树回收策略配置。服务入口在 Python 后端退出后返回同一退出码。

## 初次使用

在“设置→本地知识源”上传 Wiki ZIP（最多 50 MB，解压后最多 200 MB、10000 条目），或填写服务器可访问的 Wiki 目录。上传包可以包含一个顶层文件夹，应保留 `_agent_context/overview.md` 和 `domain-map.md`。ZIP 导入仅接收 Markdown；图片等附件不导入。添加后点击刷新知识库，页面显示索引进度。网页无法调用访问者电脑的 Windows 文件夹选择器。

在模型设置中配置 API Key、网络代理并测试；MCP、网页检索和抓取均从 Windows 服务发起，服务器须具备对应网络访问能力。桌面机原有的 localhost 代理、MCP 地址不会自动变成服务器可用地址。

新建项目→快速研究→白板编辑/AI 共创→内容资产，均由同一个服务处理。任务不依赖浏览器保持打开；服务重启会把未完成生成任务标为中断，用户可重试。数据持久化保留项目、节点、模型配置、密钥、索引及日志。

## 共享范围与网络边界

这是一个**共享工作空间**，使用同一账号的成员共享项目、知识库、模型密钥和管理设置；不是按用户隔离的多租户产品，也不保证多人同时编辑同一白板时自动合并。请只授权可信的内部使用者。通过平台内网访问控制和 HTTPS 网关发布，避免直接公开 HTTP 监听端口。登录为 HTTP Basic，必须使用 HTTPS；生产环境建议在平台设置访问权限及定期轮换密码。

公开 Release 不包含用户的私有 Wiki、数据库或模型密钥。可在服务中导入配置备份；桌面数据迁移应停机备份后复制数据库、secrets.json 与索引到持久目录，并在设置中修正服务器 Wiki 路径。API Key 保存在服务器数据目录，不嵌入前端静态文件。

## 排错

- 无法启动：检查启动日志、`CIC_SERVER_PASSWORD`、持久目录权限以及端口是否被占用。
- 网页打开但 API 失败：确认 `/api` 也映射到同一 Windows 服务，网关没有截断路径、拦截长请求或缓存 API。
- 401：核对账号密码；探针也需要登录。
- 知识库路径不存在：路径是服务器路径，不能直接使用访问者本机路径；可以改用上传 ZIP。
- 模型/MCP 不通：在服务器上配置可用代理和访问权限，使用设置中的测试功能。
- 日志：`CIC_DATA_DIR/server.log` 与平台捕获的标准错误。AI 任务日志仍可从网页导出。

## 发布验证范围

自动测试覆盖独立服务启动、HTTP Basic 登录、健康接口、前端资源、新建项目、持久化和 Wiki ZIP 导入。发布测试使用本地 Windows HTTP 环境，不代表已接入企业 cloud-deploy-app；平台实际的启动入口、端口映射、HTTPS、持久卷和出站网络仍需部署方配置。
