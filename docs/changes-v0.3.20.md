# v0.3.20 白板交互与内容简报

## 使用变化

1. 在白板空白、分组背景及节点上按住右键拖动，统一平移画布；输入框保留文字编辑右键菜单。
2. 左侧栏顶部可折叠或展开，全局生效并记忆状态；折叠后保留导航图标和文字提示。
3. 锁定分组始终处于节点下方，点击也不会升层，且不能拉伸尺寸。
4. 鼠标位于画布时按 N，按当前平移、缩放坐标创建笔记；鼠标不在画布时，以当前可见画布中心为后备位置。输入文字时不会触发快捷键。
5. 快速研究页增加可选内容简报，可填目标受众、传播目标、输出形式及限制；提供模板和单独保存按钮，开始研究前自动保存。保存后同步到“01 输入与简报”的“内容简报”节点；白板修改简报也会同步回项目。简报节点锁定时须先解锁再修改。
6. 模型研究时接收简报，用于检索规划和研究归纳的创作要求，不把简报当作事实证据。

## 验证

- 前端单元和 DOM 回归测试、生产构建。
- 后端全量测试及简报双向同步、锁定保护、缺失简报恢复测试。
- Chromium 实际交互验证：锁定与未锁定分组右拖、右键菜单抑制、分组层级、侧栏折叠、平移缩放后 N 新建位置、简报保存和全文展示。
- Windows CI 验证单体 EXE 启动、本地 API、旧进程替换后发布。
