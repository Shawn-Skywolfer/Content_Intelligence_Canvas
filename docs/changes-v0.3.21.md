# v0.3.21 联网共创与可停靠白板工具栏

## 用户流程

### 网络资料辅助加工

1. 选中一个节点或多个节点，在“AI 共创 → 新节点类型”选择洞察、质疑、创意模式或笔记。
2. 按需勾选“检索网络资料（通过设置的搜索 MCP，并与 Wiki 资料综合）”，填写处理要求后启动。
3. 后端先读取相关 Wiki 和选定层级的上游节点，再调用设置中的搜索 MCP；模型综合处理两类资料，输出下游节点并记录加工来源、网络来源。
4. 暂停、继续或失败重试时，保留该任务的网络检索选项。未启用联网时，不调用搜索 MCP；搜索 MCP 未配置或不可用时明确报错。

### 白板工具栏

- 原右上角的撤回、重做、添加节点、删除、创建分组、整理连线、按类型整理移到画布内，采用统一 SVG 图标，悬停可查看中文名称及快捷键。
- 按住六点手柄拖动，释放后吸附到最近的上、下、左、右边缘，并自动采用适合该边的方向。
- 点击工具栏末端的设置图标，可以明确选择四边停靠位置，也可独立选择横向或纵向。
- 停靠位置与显示方向在浏览器中保存，切换项目、刷新后沿用；工具栏不占用项目标题区。
- 停靠左侧、右侧或底部时，画布缩放控件或缩略图避让工具栏。

### AI 任务监测

- 点击监测栏右侧“折叠任务监测”，收起任务列表及管理按钮，保留运行、暂停、失败与总任务数量。
- 折叠不会中断或暂停任务，仍持续轮询状态；点击“展开任务监测”恢复管理。
- 折叠状态会记忆。暂停、继续、取消、重试和任务详情功能保留。

左侧品牌名称改为“内容智能工作台”。

## 验证

- 后端全量回归；四种类型均验证 Wiki 和 MCP 材料进入模型输入，来源进入生成节点；任务启动与重试保留网络选项。
