# 内容智能白板 PRD（本地绿色版）

版本：v0.3.11｜更新：2026-09-26

## 1. 产品目标与边界

让个人在本机导入内部 Wiki 等知识，用可追溯的证据研究选题，在有向白板上组织材料、联合加工、生产中文内容，并把确认后的稿件保存为可迭代的内容资产。桌面交付为单体 Windows `.exe`，用户数据保存在本机应用数据目录；应用重启后项目、知识源、模型配置、白板及资产仍可访问。浏览器界面所有操作文字均使用中文。连接外部模型由本地后端发起，浏览器不直连供应商。

## 2. 完整用户流程

1. **首次启动与设置**：运行 EXE；若上一实例仍在运行，由新实例接管。进入「设置」，点击「浏览本地文件夹」，选 Wiki 根目录，命名并创建知识源，刷新索引并查看导入结果。配置 DeepSeek、AIHubMix 或 OpenAI 兼容供应商；输入 API Key、Base URL、模型名，按网络环境选择直连、系统代理或自定义企业代理；刷新模型列表、保存并测试连接。外部模型需要按数据边界调整内部数据保护开关。未配置可用模型时，问答和研究应明确提示，不生成假研究节点。
2. **建立项目**：在「项目」输入原始想法、项目名称和内容简报，创建项目。最近项目可再次打开白板；切换项目后显示各自的数据和研究历史。
3. **提问与查证材料**：在「知识检索」选择知识源并输入问题。模型先根据问题规划 Wiki 检索词，系统用混合检索从 Markdown 和知识链接获取候选片段，模型阅读 Wiki 原文后输出中文解读及所引用的证据 ID；只展示模型引用的原文卡片。用户可展开正文和上下文，或把回答连同引用加入白板；检索设置可调结果数和各项权重。
4. **快速研究**：在「快速研究」输入问题、选择知识源并设定发现数。模型规划检索词、阅读 Wiki 证据、交叉理解，产生附证据 ID 的发现和三条内容方向。进度框显示理解、检索、生成与写入阶段；模型不可用、引用无效或数据保护拦截时失败并显示原因，不生成模板节点。完成后自动进入白板并定位生成节点；历史记录可查看或删除，删除不影响节点。
5. **组织白板**：新项目呈现按类型分组的起始模板。已有研究结果的项目用「输入与简报」「研究与证据」「洞察与策略」三列展示，研究发现按每列两条子列向下排列；未使用的演示卡片清理，已编辑或已连接的卡片保留。画布支持拖动、缩放、框选、Ctrl 多选、添加/复制/删除节点、撤回/重做、整理节点和连线；节点四边均可拖出有方向的箭头，箭头起点是上游、终点是下游。
6. **编辑、分组与 AI 加工**：节点卡片默认渲染 Markdown，双击正文直接输入 Markdown；在右侧详情可修改标题、正文、状态，拖动节点边角调整显示大小，完整内容可滚动查看。选择单节点或框选多个节点后输入 Prompt，点击「AI 加工并生成下游节点」：原节点保留，新节点带有到来源节点的有向连接；模型同时读取选中节点及它们的上游上下文。若先「创建分组」，选中分组可一次加工全部成员；新节点详情明确列出直接来源标题、节点 ID、继承的上游节点、证据及加工要求。手工修改只影响当前节点。
7. **内容生产与沉淀**：从白板选中的节点生成公众号文章、短视频脚本或营销活动稿；弹窗填写形式、标题、时长及创作风格，进度框显示生成阶段。输出先形成可编辑白板节点，可继续 Markdown 编辑或沿有向连接迭代；确认后保存到「内容资产」，再次保存形成新版本。可查看资产及导出项目和稿件。
8. **异常恢复**：打开项目、研究完成跳转或点击历史记录，都必须进入同一白板。若接口读取失败，显示错误与「重新读取白板」；此操作不得删除或覆盖内容。离线时已保存的白板、资产仍可浏览和手工编辑；依赖模型的提问、快速研究与 AI 共创须明确提示调用失败，不将关键词片段或固定模板伪装为模型结论。

## 3. 功能与交互规则

| 模块 | 功能及规则 | 验收重点 |
| --- | --- | --- |
| 本地运行 | 单体 EXE、旧进程接管、本机数据长期保留、后端代理外部模型请求 | 双击启动，二次启动替换旧进程；配置和知识源重启后仍在 |
| 知识源 | 本地文件夹选择、Wiki Markdown 解析、索引刷新、知识源增删 | 真实 Wiki 可被检索且展示标题层级和出处 |
| 模型驱动 Wiki 问答 | 模型规划检索词；混合召回后阅读 Wiki 原文、回答问题，校验模型引用的证据 ID | 检索答复不再只是摘录，引用对应真实 Wiki 文件、标题和行号 |
| 模型配置 | DeepSeek、AIHubMix、兼容自定义供应商；获取模型、测试连接、代理配置 | 可诊断网络和鉴权错误；代理设置随配置保存 |
| 项目 | 创建、选择、继续编辑、研究/白板/资产关联 | 跨页面、跨重启保持正确项目 |
| 快速研究 | 模型依据真实 Wiki 生成发现与三条方向，保留进度、运行模型与历史记录 | 模型失败不新增节点，成功节点含模型与证据出处 |
| 白板 | 三列动态布局、四向有向连接、连线整理、框选、分组、拖拽缩放、快捷键、撤回/重做 | 节点不会遮挡；拖动稳定；尺寸重启后保持 |
| AI 共创 | 单/多节点以及分组统一生成下游；继承有向上游；来源、证据可查看 | 原节点正文不被覆盖，新节点与每个来源都有连线 |
| 内容资产 | 白板里生成稿件、修改、保存/更新资产、导出 | 先编辑再保存，资产版本可以追踪 |

## 4. 白板数据语义

- 每个节点包含类型、标题、Markdown 正文、状态、尺寸、位置、创建者、证据与加工元信息。
- 连线具有明确的 `source_node_id` 与 `target_node_id`；从任意四个连接点开始拖拽，目标节点为下游。生成上下文按有向边回溯上游，须防循环、去重。
- AI 新节点保留 `source_node_ids`、来源标题、`inherited_upstream_ids`、研究/模型运行记录及继承证据；页面必须能直接看到直接来源。
- 分组保存成员 ID；移动分组时成员一起移动，选中分组时 AI 使用成员正文而非空白分组框。
- 历史研究是任务记录，不等于白板节点生命周期。默认删除历史只删除该记录。
- 旧数据迁移只能安全补齐空画布或演示布局；读取现有白板时必须保护用户编辑、节点尺寸和自建连接。失败时保留原白板并显示可诊断错误。

## 5. 快捷键

| 操作 | 快捷键 |
| --- | --- |
| 新建节点 | N |
| 删除选中节点/连线 | Delete / Backspace |
| 撤回与重做 | Ctrl/Cmd+Z；Ctrl/Cmd+Shift+Z 或 Ctrl/Cmd+Y |
| 全选、复制选中 | Ctrl/Cmd+A；Ctrl/Cmd+D |
| 移动节点 | 方向键 |
| 清除选择 | Esc |
| 完成 Markdown 编辑 | Ctrl/Cmd+Enter 或移出输入框 |

## 6. 验收场景与非目标

用真实 Wiki 完成「设置知识源 → 配置并测试模型 → 提问获得带原文引用的答复 → 快速研究 → 从历史进入白板 → 合并多个节点 → 生成公众号草稿 → 保存内容资产 → 重启继续」；模型断线或受数据保护拦截时验证不生成伪造节点。Windows 构建需实际启动 EXE，校验健康接口及旧实例替换。模拟模型测试不能视为真实供应商 API 已通过。

本期不包含团队实时协作、云端知识源自动同步和自动发布到第三方平台。

## 7. v0.3.11 修复验收

- 从 v0.3.8 等旧版升级后，启动器必须解包并运行 v0.3.11 的新运行时，不能沿用旧的 `.ready` 缓存；旧运行时与用户数据互不覆盖。
- 模型扩展检索词的候选材料在 30 条窗口中保留席位；模型引用未知证据 ID 时明确失败。
- 研究发现过滤无效证据后，内容方向的来源索引仍正确指向通过验证的发现。
