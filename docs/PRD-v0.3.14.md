# 内容智能白板 PRD（本地绿色版）

版本：v0.3.14｜更新：2026-10-08

## 1. 产品目标与边界

让个人在本机导入内部 Wiki 等知识，用可追溯的证据研究选题，在有向白板上组织材料、联合加工、生产中文内容，并把确认后的稿件保存为可迭代的内容资产。桌面交付为单体 Windows `.exe`，用户数据保存在本机应用数据目录；应用重启后项目、知识源、模型配置、白板及资产仍可访问。浏览器界面所有操作文字均使用中文。连接外部模型由本地后端发起，浏览器不直连供应商。

## 2. 完整用户流程

1. **首次启动与设置**：运行 EXE；若上一实例仍在运行，由新实例接管。进入「设置」，点击「浏览本地文件夹」，选 Wiki 根目录，命名并创建知识源，刷新索引并查看导入结果。配置 DeepSeek、AIHubMix 或 OpenAI 兼容供应商；输入 API Key、Base URL、模型名，按网络环境选择直连、系统代理或自定义企业代理；刷新模型列表、保存并测试连接。外部模型需要按数据边界调整内部数据保护开关。未配置可用模型时，快速研究和 AI 共创应明确提示，不生成假研究节点。设置页还能配置各输出形态的默认正向与负向 Prompt。
2. **建立项目**：在「项目」输入原始想法、项目名称和内容简报，创建项目。最近项目可再次打开白板；切换项目后显示各自的数据和研究历史。项目可归档、恢复，永久删除前须二次确认并提示先导出。
3. **从 Wiki 开始研究**：在「快速研究」选择知识源并输入问题。模型先规划检索词，系统用混合检索从 Markdown 和知识链接获取候选片段；模型阅读 Wiki 原文后综合理解并给出带出处的发现。独立知识检索入口已移除。
4. **快速研究**：在「快速研究」输入问题、选择知识源并设定发现数。模型规划检索词、阅读 Wiki 证据、交叉理解，产生附证据 ID 的发现和三条内容方向。进度框显示理解、检索、生成与写入阶段；模型不可用、引用无效或数据保护拦截时失败并显示原因，不生成模板节点。完成后自动进入白板并定位生成节点；历史记录可查看或删除，删除不影响节点。
5. **组织白板**：新项目呈现按类型分组的起始模板。已有研究结果的项目用「输入与简报」「研究与证据」「洞察与策略」三列展示，研究发现按每列两条子列向下排列；未使用的演示卡片清理，已编辑或已连接的卡片保留。画布支持拖动、缩放、框选、Ctrl 多选、添加/复制/删除节点、撤回/重做、整理节点和连线；节点四边均可拖出有方向的箭头，箭头起点是上游、终点是下游。
6. **编辑、分组与 AI 加工**：节点卡片默认渲染 Markdown，双击正文直接输入 Markdown；在右侧详情可修改标题、正文、状态，拖动节点边角调整显示大小，完整内容可滚动查看。选择单节点或框选多个节点后输入 Prompt，点击「AI 加工并生成下游节点」：原节点保留，新节点带有到来源节点的有向连接；模型同时读取选中节点及它们的上游上下文。若先「创建分组」，选中分组可一次加工全部成员；新节点详情明确列出直接来源标题、节点 ID、继承的上游节点、证据及加工要求。手工修改只影响当前节点。
7. **内容生产与沉淀**：从白板 AI 共创选择“内容输出”及已配置的形态（也可使用集中内容弹窗），填写本次正向、负向 Prompt，进度框显示生成阶段。输出先形成与来源有向连接的可编辑白板节点；确认后保存到「内容资产」。资产页按项目查看已确认稿件，可二次修改并同步白板、导出、删除。
8. **异常恢复**：打开项目、研究完成跳转或点击历史记录，都必须进入同一白板。若接口读取失败，显示错误与「重新读取白板」；此操作不得删除或覆盖内容。离线时已保存的白板、资产仍可浏览和手工编辑；依赖模型的快速研究与 AI 共创须明确提示调用失败，不将关键词片段或固定模板伪装为模型结论。

## 3. 功能与交互规则

| 模块 | 功能及规则 | 验收重点 |
| --- | --- | --- |
| 本地运行 | 单体 EXE、旧进程接管、本机数据长期保留、后端代理外部模型请求 | 双击启动，二次启动替换旧进程；配置和知识源重启后仍在 |
| 知识源 | 本地文件夹选择、Wiki Markdown 解析、索引刷新、知识源增删 | 真实 Wiki 可被检索且展示标题层级和出处 |
| 模型驱动 Wiki 研究 | 模型规划检索词；混合召回后阅读 Wiki 原文、生成发现，校验引用的证据 ID | 研究结论引用对应真实 Wiki 文件、标题和行号；没有独立检索页面 |
| 模型配置 | DeepSeek、AIHubMix、兼容自定义供应商；获取模型、测试连接、代理配置 | 可诊断网络和鉴权错误；代理设置随配置保存 |
| 项目 | 创建、选择、归档、恢复、永久删除；研究/白板/资产关联 | 跨页面、跨重启保持正确项目；删除仅级联该项目 |
| 快速研究 | 模型依据真实 Wiki 生成发现与三条方向，保留进度、运行模型与历史记录 | 模型失败不新增节点，成功节点含模型与证据出处 |
| 白板 | 三列动态布局、四向有向连接、连线整理、框选、分组、拖拽缩放、快捷键、撤回/重做 | 节点不会遮挡；拖动稳定；尺寸重启后保持 |
| AI 共创 | 单/多节点以及分组统一生成下游；内容输出可选自定义形态并继承有向上游 | 原节点正文不被覆盖，新节点与每个来源都有连线；默认及本次 Prompt 可追溯 |
| 内容资产 | 按项目列出已确认白板输出，提供二次修改同步节点、导出、删除 | 不再提供独立生成表单；资产版本可追踪，删除资产保留白板草稿 |

## 4. 白板数据语义

- 每个节点包含类型、标题、Markdown 正文、状态、尺寸、位置、创建者、证据与加工元信息。
- 连线具有明确的 `source_node_id` 与 `target_node_id`；从任意四个连接点开始拖拽，目标节点为下游。生成上下文按有向边回溯上游，须防循环、去重。
- AI 新节点保留 `source_node_ids`、来源标题、`inherited_upstream_ids`、研究/模型运行记录及继承证据；页面必须能直接看到直接来源。
- 分组保存成员 ID；移动分组时成员一起移动，选中分组时 AI 使用成员正文而非空白分组框。
- 历史研究是任务记录，不等于白板节点生命周期。默认删除历史只删除该记录。
- 旧数据迁移只能安全补齐空画布或演示布局；读取现有白板时必须保护用户编辑、节点尺寸和自建连接。失败时保留原白板并显示可诊断错误。

## 6. 验收场景与非目标

用真实 Wiki 完成「设置知识源与输出形态 → 配置并测试模型 → 快速研究 → 从历史进入白板 → 合并多个节点 → 选择输出形态生成草稿 → 保存内容资产 → 二次编辑并导出 → 归档与恢复 → 重启继续」；模型断线或受数据保护拦截时验证不生成伪造节点。Windows 构建需实际启动 EXE，校验健康接口及旧实例替换。模拟模型测试不能视为真实供应商 API 已通过。

本期不包含团队实时协作、云端知识源自动同步和自动发布到第三方平台。

## 7. v0.3.11 修复验收

- 从 v0.3.8 等旧版升级后，启动器必须解包并运行 v0.3.11 的新运行时，不能沿用旧的 `.ready` 缓存；旧运行时与用户数据互不覆盖。
- 模型扩展检索词的候选材料在 30 条窗口中保留席位；模型引用未知证据 ID 时明确失败。
- 研究发现过滤无效证据后，内容方向的来源索引仍正确指向通过验证的发现。

## 8. v0.3.12 节点摘要与全文展开

- 白板节点卡片显示模型基于节点完整正文生成的不超过 60 字的中文摘要，不把原文片段或固定模板冒充为模型摘要。旧节点进入白板后按需补齐摘要，生成后持久化；无正文的节点和分组不调用模型。
- 点击卡片上的『展开全文』打开可滚动的完整 Markdown，标题、正文与模型摘要同屏，关闭后回到原位置；双击正文仍可直接编辑。
- 编辑标题或正文使旧摘要失效并重新生成；模型生成期间发生编辑时，旧摘要不得写回新正文。模型未配置、网络故障或数据保护阻止时，正文仍可展开阅读，页面显示失败原因并支持手动重试。
- 用户同意外部模型读取内部内容才会发送摘要请求；长正文分段处理后再压缩成卡片摘要。

## 9. v0.3.13 曲线连线与输出 Prompt

- 白板所有有向连线采用四向端口对应的贝塞尔曲线，保留箭头方向和手工连接关系。选中单个或多个节点时，只有与选中节点直接相连的边沿从上游到下游的方向显示流动虚线；取消选中后恢复静态线。减少动态效果偏好下停止动画。
- 在「生成新内容」弹窗和侧栏选择「内容输出」的 AI 共创中，分别输入正向 Prompt（要做的事情）和负向 Prompt（不要做的事情）。负向 Prompt 可以留空；创建时两项分别传入模型，模型应遵守证据约束，并将两项记录在新节点元数据中，便于后续追溯。旧接口缺省负向 Prompt 时仍按原有要求执行。
- 验收：从一个节点创建有向边，选中其上游或下游时观察箭头方向流动；取消选中确认恢复；从内容工坊和 AI 共创分别提交两组要求，查看模型输入与新节点元数据；在 Windows EXE 中重复以上操作。

## 10. v0.3.14 项目与内容资产流程调整

### 项目

- 新建项目后进入快速研究，再进入白板。项目页按“进行中”和可折叠的“已归档”列出项目。每张卡片可打开、归档、恢复或删除；侧栏当前项目选择器只显示进行中项目。
- 归档保留全部研究、白板、资产和模型记录，可恢复后继续工作。删除必须二次确认，说明会删除该项目的研究、节点、连线和资产且不可撤销；删除前可先导出。删除通过数据库外键级联完成，不影响其他项目或全局知识库。

### 研究与白板

- 导航移除独立“知识检索”。快速研究是研究主入口，仍由模型理解问题、检索并阅读本地 Wiki、生成含证据的发现与方向。旧检索 API 保留供内部检索流程使用，既有白板知识节点不被清除。
- 白板的 AI 共创选择“内容输出”时，直接出现内容形态、视频时长（适用时）、正向及负向 Prompt。处理后自动生成有向连接的下游输出节点，记录直接来源、上游上下文、形态及本次和默认 Prompt 的快照；原节点保留。工具栏的“生成新内容”仍作为集中编辑弹窗，调用相同的输出流程。
- 在“设置 → 内容输出形态与 Prompt”可修改现有形态的名称与默认正向/负向 Prompt，也可新增最多 20 种内容形态。标识生成后固定；保存后对下一次生成生效，旧节点中的 Prompt 快照不回写。模型仍遵守证据边界；未配置可用模型时明确失败。

### 内容资产

- 内容资产页以当前项目为范围，只显示在白板输出节点中点击“保存到内容资产”的已确认稿件。内容生成控件从该页移除。切换项目立即查看对应资产。
- 展开资产查看完整 Markdown、证据数量和版本；可二次修改标题与正文并保存新版本，同步修改关联白板节点；支持单项 Markdown 导出与项目导出。删除资产时二次确认，仅解除关联并删除资产记录，白板输出节点保留为可编辑草稿。锁定的关联节点须先解锁才允许同步修改。
- 旧版资产无关联节点时仍可查看、编辑、导出和删除；不凭空创建节点。修改正文后节点已有的模型摘要失效，需要重新生成。

### 验收路径

建立两个项目 → 在其一完成快速研究 → 白板 AI 共创选择自定义形态并填写两组 Prompt → 编辑输出节点 → 保存为资产 → 在资产页二次修改与导出 → 切换到另一个项目确认资产隔离 → 返回归档与恢复第一个项目 → 导出备份后删除并确认级联清理。
