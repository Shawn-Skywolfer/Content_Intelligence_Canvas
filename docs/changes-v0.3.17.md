# 内容智能白板 v0.3.17 使用说明

## 知识源

- 在“设置 → 知识源”粘贴路径或点击“浏览文件夹”。若路径前意外带有 `[WARNING] Ignore caches that are heterogeneous` 等输出，输入框和服务端会识别并保留实际的 Windows 盘符路径。添加失败会在表单下方显示原因。
- 点击该知识源的“刷新知识库”后，卡片内实时显示模型阅读阶段、当前词条、处理数量、已更新与未变更数量、警告数、已用时和预计总时长。模型尚在阅读全局上下文或扫描期间，预计时长会显示“计算中”。页面切换后返回设置可恢复当前进度；应用重启时未完成的进度记录不会恢复，但已经写入的索引保留。
- 索引警告可展开逐条查看。模型阅读失败与索引失败分别显示，不会把模型失败冒充为成功读取。

## 模型和 MCP

- 模型配置可刷新供应商返回的全部模型，把多个模型加入当前供应商的可调用列表，选择当前调用的模型并保存。不同供应商配置也可独立保存。通过“设为默认调用模型”明确决定后续研究与共创使用哪项已保存配置。
- 模型数据边界明确标为“外部”或“内部”。开启内部数据保护时，仅已标记为“内部”的模型可接收 Wiki 与白板资料；标签由使用者根据实际部署和企业数据策略设置。
- 模型与搜索 MCP 的保存、连接测试、模型列表获取会在所在标签页展示等待时长、目标、网络方式、返回状态或失败原因。连接测试只报告真实接口返回，不推测尚未完成的网络阶段。

## 白板 AI 共创

- 选择“可继承的上游节点层级”：不继承、1 层、2 层、3 层、6 层（默认）或 12 层；页面显示当前范围内的上游节点数量。实际生成的节点记录继承层级与来源节点 ID。
- 每个选中节点或节点组合独立保留未提交的 AI 共创草稿。切换其他节点后不会串用 Prompt；切回原节点恢复草稿。任务提交成功后只清空该组选中节点的草稿。
- AI 任务监测栏位于白板下方。点击“取消”会立即标记任务为已取消，并尝试关闭正在进行的模型或搜索连接；即使远端稍后返回，也不会把结果写成新的下游节点。已完成的任务不能取消。

本公开 Release 不打包用户的私有 Wiki 和 API Key；本地测试继续使用用户已配置的数据目录。Windows 构建流程验证前后端测试、单体 EXE 启动与旧实例替换后发布。
