# Wiki 全局上下文接入（v0.3.16）

把 `_agent_context` 放在已添加的知识源根目录下：

```text
Wiki/
  _agent_context/
    overview.md
    domain-map.md
    relations.md
    claims.md
    structure.md
    reading-progress.md
  原始词条.md
```

## 使用流程

1. 打开「设置 → 本地知识源」，对目标知识源点击「刷新知识库」。应用先把完整的 `overview.md` 与 `domain-map.md` 发送给当前配置并获准读取内部知识的大模型，确认模型返回了理解摘要，再增量扫描原始词条。
2. 刷新结果分别显示索引数量与模型阅读状态。模型没有配置、资料不完整、网络或权限失败时，仍可完成原始词条索引，但会明确显示失败原因。
3. 发起快速研究或检索时，本次模型调用重新读取 `overview.md` 和 `domain-map.md`，先规划检索问题。若模型判断涉及实体关系或证据链，则再读取 `relations.md`，细化针对原始词条的检索表达。
4. 原始词条进入混合检索；回答与研究发现使用原始词条分块核对证据。全局导航会同时传给最终的分析模型，但不能单独充当可引用事实。

`claims.md`、`structure.md` 和 `reading-progress.md` 保留在目录中；本版不会自动作为每次研究的必读资料。`_agent_context` 下的文件也不会混入普通索引。若两份必需文档只缺一份，研究任务会直接报告缺失文件，避免静默跳过。

这是公开源代码与程序包；私有 Wiki 和 API Key 仍留在用户本机的数据目录。需要验证自己的 Wiki 时，先选择其根目录、配置模型和数据保护授权，再进行手动刷新和快速研究。
