# 内容智能白板 v0.3.19

## 模型配置与代理

- 修复字段校验错误显示为 `[object Object]`，现在显示具体字段及限制。
- 最大输出 token 的可配置范围统一为 1–262144；保存和测试结果分别显示，保存失败不再出现测试文本、请求地址和模型通过/失败的混杂信息。
- 最大输出数字框支持清空后重新输入，不再自动补 `0`；200000、256000 的配置值可保存。
- 测试结束后固定耗时，不再持续累计。
- 增加“保存并设为默认”，明确展示研究与白板实际使用的默认模型。测试其他供应商配置不会自动切换默认模型。
- 每次白板任务记录模型、接口及网络配置，并在本次任务中保持一致。执行详情记录真实线路尝试及 HTTP 结果。

## 白板任务管理

- 显示全部历史任务，可按运行中、暂停、失败、取消、完成筛选；支持多选和批量操作。
- 运行中可暂停或取消；暂停后可继续；失败或取消后可重试，失败记录也可取消。
- 暂停会阻止本次执行继续写入结果，并尽力关闭本地网络连接。供应商接口不支持从暂停位置续写，继续会使用当前默认模型重新执行；已送达供应商的请求仍可能计费。
- 保存 Prompt、上下文继承层级、输出形态等任务参数。重新打开应用后仍可查看、继续或重试任务。
- 可再次点击任务标题或“查看详情”，查看完整错误、Prompt、输入节点当前内容、执行日志和完整结果。
- 旧版任务没有保存 Prompt 时，可以在详情中补充要求后重试；应用不会凭空恢复已经丢失的创作要求。
- 每次执行使用独立令牌与执行编号，防止暂停或重试前的旧请求晚返回后覆盖新状态、重复生成节点。
