# 内容智能白板 v0.3.18

## 设置与模型管理

- 在“已保存的供应商与模型”中选择配置后，可删除配置及保存在本机的对应密钥。若删除当前调用模型，应用会选择另一项已启用的模型。
- 设置页顶部可以导出、导入 JSON 配置。包含知识源路径、模型、代理、MCP、内容形态、数据保护和 API Key；不包含 Wiki 原文、索引及项目内容。导出的密钥是明文，请仅保存在可信设备。导入时跳过当前机器上不存在的知识源路径并提示重新选择。
- 模型高级设置可指定思考参数（不附加、`reasoning_effort`、`thinking.enabled`）、思考强度、测试模型、每条线路的测试超时和输出上限。供应商不支持的参数应保持“不附加”。
- 可配置供应商提供的额度查询接口、JSON 字段路径和显示单位；保存后手动查询。不同供应商没有统一的额度 API，无法凭模型调用用量推算账户余额。

## 连接诊断

- “短文本实测”向已保存的模型发送“请只回复 OK”，通过页面内任务框实时显示选择连接线路、等待响应、解析结果等阶段。
- 默认每条线路超时 15 秒；自动网络模式可能依次尝试系统代理和直连。测试超时与生成内容时的请求超时彼此独立。
- HTTP 200 只说明接口接受了请求。只有解析出实际文本才显示测试通过；只有思考内容、输出额度耗尽或空文本均显示失败，并展示结束原因、响应节选和本次 token 用量（供应商有返回时）。
- 设置页标题只显示一次“设置”。
